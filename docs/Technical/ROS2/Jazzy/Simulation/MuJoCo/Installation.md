## MuJoCo ROS2 Control Installation

To install MuJoCo ROS2 Control, use the following command:

```bash
sudo apt-get install -y ros-jazzy-mujoco-ros2-control
```

- This package will install everything needed for getting a MuJoCo simulation running.

You can optionally install demos, downloadable by:

```bash
sudo apt-get install -y ros-jazzy-mujoco-ros2-control-demos
```

- This includes some extra launch file used for demonstration of MuJoCo ROS2 Control working.
