## macOS Setup

Here you will find how to get set up with development tools for macOS. There are two methods. For most people it is recommended to start with the Docker setup, as it is the easiest to get started. If more advanced configuration is required, it may be better to use the Virtual Machine setup.

It is also required to [Install VSCode]({% link docs/Non-Programmer Friendly Zone/How-to-Use-VSCode.md %}) first.

Once installed, go through the Table of Contents.
