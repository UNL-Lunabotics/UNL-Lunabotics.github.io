# Technical

This folder contains tutorials on how to set up development tools for most platforms. To get started, follow the tutorial for your operating system.

{: .note}
There are two macOS guides. It is recommended to follow the [macOS Docker]({% link docs/Development Tools/Technical/macOS-Docker.md %}) guide as it is simpler. If USB passthrough is required, then follow the [macOS Virtual Machine]({% link docs/Development Tools/Technical/macOS-Virtual-Machine.md %}) guide.
