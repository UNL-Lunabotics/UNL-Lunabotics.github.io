## Getting Started

This page is written to be the very place you go when joining the programming team. It will walk you through your onboarding process and getting the development tools set up. It assumes you have 0 programming experience.

## Necessary Installations

The two basic things that you will need no matter what you work on are [VSCode](#vscode), [Git](https://git-scm.com/).

### VSCode

[VSCode](https://code.visualstudio.com/) is an Integrated Development Environment (IDE) where you will actually edit code. The important thing to know about VSCode is that it is technically just a text editor. However, it has this feature called extensions. If you open the extensions menu and search for whatever programming language you want to use, you can find the corresponding extension that will enable you to run the code.

{: .note}
You HAVE to install the language's extension to be able to use it (most of the time). All the extension in VSCode does is enable you to use a programming language you have already downloaded the software for. You still have to download the language's SDK (most of the time). Usually, you can find this software by googling the language's name plus 'SDK', so for example, 'Python SDK'. SDK stands for Software Development Kit, and it is what allows you to actually run the software. Some languages, such as C++, are compiled, and you do not need to download their SDK and instead need to download the compiler that they use.

To install VSCode, go to [this](https://code.visualstudio.com/Download?_exp_download=d53503e735) link, select your specific operating system, and follow its download instructions.

It is recommended that you set up a Lunabotics [profile](https://code.visualstudio.com/docs/configure/profiles) in VSCode for all the extensions you will be using.

### Git

[Git](https://git-scm.com/) is a version control software that lets you download code from [GitHub](https://github.com/). You will need it in order to actually download the code that we use and be able to change anything.

{: .important}
If you haven't already, make a GitHub account.

To install Git, go to [this](https://git-scm.com/install/) page, select your operating system, and follow the instructions.
